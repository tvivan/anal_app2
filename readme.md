# Interactive CSV Analyst

Этот проект представляет собой веб-приложение для интерактивного анализа CSV-файлов с использованием больших языковых моделей (LLM). Пользователи могут загружать свои данные, задавать вопросы на естественном языке, а система будет генерировать и выполнять код на Python (Pandas) для получения ответов.

Проект предлагает два способа запуска:
1.  **Streamlit App (Рекомендуется):** Готовое к использованию, интерактивное веб-приложение с дружелюбным интерфейсом.
2.  **FastAPI Backend:** "Безголовый" бэкенд с REST API, предназначенный для разработчиков, которые хотят создать свой собственный frontend (например, на React, Vue, Svelte).

## Основные возможности

*   **Интерактивный чат:** Задавайте вопросы о ваших данных на естественном языке.
*   **Гибкая конфигурация:** Настраивайте подключение к Redis, выбирайте LLM-провайдера, модель и вводите API-ключ прямо в интерфейсе.
*   **LLM-генерация кода:** Интеграция с OpenAI-совместимыми API для преобразования запросов в исполняемый код Pandas.
*   **Безопасное выполнение:** Код выполняется в изолированном окружении, оперируя копией DataFrame.
*   **Управление состоянием:** Возможность отменять (Undo) и повторять (Redo) действия благодаря сохранению состояний DataFrame в Redis.
*   **Два режима развертывания:** Используйте готовый интерфейс Streamlit или подключите свой фронтенд к API на FastAPI.

## Архитектура проекта

Ключевая особенность проекта — модульная архитектура. Оба способа запуска (Streamlit и FastAPI) используют **общую кодовую базу** для всей бизнес-логики.

1.  **Общая логика (`functions/` и `endpoints/`)**
    *   `api_integration.py`: Универсальный клиент для работы с LLM-провайдерами.
    *   `memory.py`: Менеджер состояний для работы с Redis и Parquet.
    *   `df_code_analys.py`, `prompts.py`: Ядро для выполнения кода и генерации промптов.
    *   `endpoints.py`: Pydantic-модели, используемые для валидации данных.

2.  **Подход 1: Streamlit App (`streamlit_app.py`)**
    *   Это основной и рекомендуемый способ запуска.
    *   Файл `streamlit_app.py` использует общую логику для создания полноценного интерактивного приложения.
    *   Он отвечает за отрисовку всего интерфейса, управление состоянием сессии пользователя (`st.session_state`) и вызов бэкенд-функций напрямую.

3.  **Подход 2: FastAPI Backend (`app.py`)**
    *   Этот файл предоставляет RESTful API для взаимодействия с ядром приложения.
    *   Он не имеет собственного интерфейса (кроме авто-документации Swagger).
    *   Предназначен для разработчиков, которые хотят интегрировать эту логику в свои системы или создать кастомный frontend. Эндпоинты (`/upload`, `/chat/{id}`) полностью функциональны и готовы к использованию.

## Инструкция по локальному запуску

### Шаг 1: Предварительные требования

*   **Python 3.9+**
*   **Redis:** Локально установленный и запущенный сервер Redis. Простейший способ — использовать [Docker](https://www.docker.com/):
    ```bash
    docker run -d -p 6379:6379 --name my-redis redis
    ```

### Шаг 2: Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <https://github.com/tvivan/Chat-with-your-CSV>
    cd tvivan-Chat-with-your-CSV
    ```
2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    # Windows
    python -m venv venv && venv\Scripts\activate
    # macOS/Linux
    python -m venv venv && source venv/bin/activate
    ```
3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

### Шаг 3: Настройка переменных окружения (Опционально)

Вы можете создать файл `.env` в корне проекта, чтобы задать значения по умолчанию для настроек.

**Пример `.env`:**
```env
# URL для Redis будет использован как значение по умолчанию в интерфейсе
REDIS_URL="redis://localhost:6379/0"

# API ключ можно оставить пустым, т.к. он вводится в UI
OPENROUTER_API_KEY=""
```

## Способы запуска

### ✅ Вариант 1: Запуск Streamlit приложения (Рекомендуется)

Этот способ запустит готовое веб-приложение.

1.  Убедитесь, что ваш Redis сервер запущен.
2.  Выполните в терминале:
    ```bash
    streamlit run streamlit_app.py
    ```
3.  В вашем браузере автоматически откроется вкладка с приложением (`http://localhost:8501`).
4.  Настройте подключения (Redis, LLM провайдер, API ключ) в боковой панели, загрузите CSV-файл и начните анализ.

### ⚙️ Вариант 2: Запуск FastAPI бэкенда (Для разработчиков)

Этот способ запустит только API-сервер. Используйте его, если вы хотите создать свой собственный frontend.

1.  Убедитесь, что ваш Redis сервер запущен, а API-ключ указан в файле `.env` или в коде `app.py`.
2.  Выполните в терминале:
    ```bash
    uvicorn app:app --reload
    ```
3.  Сервер будет доступен по адресу `http://127.0.0.1:8000`.
4.  Вы можете изучить все доступные эндпоинты в интерактивной документации Swagger по адресу `http://127.0.0.1:8000/docs`.
